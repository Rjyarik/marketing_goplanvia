# Шаблоны отчётов

## Еженедельный отчёт

```markdown
# Неделя <номер>, <даты>

## Главное
<2–3 предложения: что изменилось и что из этого следует>

## Цифры
| Метрика | Эта неделя | Прошлая | Цель к рубежу |
|---|---|---|---|
| Групповые поездки | | | |
| Посетители | | | |
| Переходы из Google и Bing | | | |
| Созданные планы | | | |
| Регистрации | | | |
| Страниц в индексе | | | |
| Опубликовано: страниц / роликов / ответов | | | |

## Каналы
| Канал | Визиты | Планы | Решение: удвоить / оставить / остановить |
|---|---|---|---|

## Что сделано
- …

## Ждёт Ярослава
- …

## План на следующую неделю
- …
```

## Отчёт фактчекера

```markdown
# Фактчек: <черновик>

Черновик: <путь к файлу>
Вердикт: пропускаю / пропускаю после правок / не пропускаю

| # | Утверждение | Источник | Проверено | Вердикт | Что заменить |
|---|---|---|---|---|---|
| 1 | | | YYYY-MM-DD | верно / неверно / не подтвердилось | |

## Утверждения о продукте
<что обещано и есть ли это в продукте>

## Стоп-слова и бренд
<найдено / не найдено>
```
