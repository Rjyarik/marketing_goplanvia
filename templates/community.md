# Шаблоны ответов для Reddit и Quora

Это каркасы, а не готовые тексты. Каждый ответ пишется под конкретный тред, с проверенными цифрами. Одинаковые тексты в разных тредах запрещены. Публикует только Ярослав.

## 1. Проверка перегруженного маршрута

Когда: человек выложил план «4 города за 6 дней» для компании.

```markdown
You've got 4 cities in 6 days with a group of 5. That's roughly [X] hours
of transit — most of two full days — based on [operator] timetables.

What I'd change:
- Drop [city] or make it a day trip from [base].
- Keep one base for 3 nights: fewer check-ins, fewer "who has the keys" moments.
- Leave one afternoon unplanned. Groups always run late.

Rough cost per person for this version: €[X] (prices checked [month]).
```

Ссылку не даём.

## 2. Бюджет на компанию

Когда: «How much money do we need for 3 days in Porto?»

```markdown
For 4 people, 3 nights in Porto in [month], prices checked on [date]:

| | Per person |
|---|---|
| Apartment for 4 | €[X] |
| Airport metro + local transport | €[X] |
| Food (cafés + one dinner out) | €[X] |
| 2 paid activities | €[X] |
| Total | ~€[X] |

The biggest swing is accommodation: [specific, checked tip].
```

Ссылка — только если у нас есть страница с этой раскладкой, и только после первых 2–3 недель.

## 3. Как планировать с друзьями без ссор

Когда: вопрос про логистику и конфликты в группе.

```markdown
What has worked for the groups I've organised:
1. One owner per decision (dates, stay, transport), not one person owning everything.
2. Agree a budget range before anyone opens a booking site.
   "Under €60/night per person" ends half the arguments.
3. Vote on dates with a 48-hour deadline, then the majority wins.
4. Plan ~70% together, leave ~30% free.
5. Log shared costs from day one, not at the airport on the way home.
```

Ссылку не даём.

## 4. «Каким приложением пользуетесь?»

Когда: тред-подборка инструментов.

```markdown
Depends on the job:
- Saving lots of places and building your own itinerary: Wanderlog does this well.
- Keeping booking confirmations in one place: TripIt.
- Just splitting money: Splitwise.
- Getting a day-by-day plan with a map fast, then sharing it with friends:
  that's what we're building at PlanVIA. Disclosure: I work on it, so I'm biased.
  Tell me what's missing and I'll pass it on.
```

Честное упоминание с раскрытием связи. Не обещаем групповых функций, которых ещё нет.

## 5. Длинный ответ на Quora

Когда: вопрос, который приводит трафик из поиска.

Структура: ответ с цифрой в первых двух строках → шаги → таблица → личный опыт → строка о себе и связи с PlanVIA → одна ссылка на самую полезную страницу (Cost Index или маршрут), а не на главную.
